## 🥇 Способ 1. VARA Public Register — официальный список всех крипто-компаний Дубая

**Мало кто знает:** регулятор Дубая (VARA) ведёт публичный реестр всех лицензированных крипто-компаний (~50 VASP).

🔗 [vara.ae/en/licenses-and-register/public-register](https://www.vara.ae/en/licenses-and-register/public-register/)

**Как использовать:**
1. Открыть реестр → получить полный список легальных работодателей
2. Пройтись по каждому → карьерная страница (обычно `/careers`)
3. Искать Android/Mobile Engineer

**Кто там (по данным на 2025–2026):**
| Компания | Тип | Заметки |
|----------|-----|---------|
| **Bybit** | Биржа | Дубай HQ, русскоязычные команды |
| **OKX** | Биржа | Большой офис в Дубае |
| **Binance** | Биржа | В VARA-реестре |
| **Crypto.com** | Биржа/платежи | Дубай-хаб |
| **BitOasis** | Биржа | Локальная дубайская |
| **Backpack.Exchange** | Биржа/кошелёк | Быстро растёт |
| **CoinMENA** | Биржа | Региональная |
| **Bitpanda, BitGo, HashKey** | Разное | Через UAE-юрлица |
| + ещё ~40 | — | Полный список в реестре |

**Плюс Абу-Даби:** [ADGM](https://www.adgm.com/) — второй крипто-хаб ОАЭ, тоже ведёт реестр лицензиатов.

## 🥉 Способ 3. LinkedIn — таргетированная тактика (самый эффективный)

### Поиск вакансий
```
Keywords: "Android" 
Location: Dubai, United Arab Emirates
```
+ алерт на этот поиск.

### Прямой outreach к рекрутерам (главное!)
1. Ищи людей: `recruiter OR "talent acquisition" + Bybit / OKX / Crypto.com / Bitget`
2. Фильтр Location = Dubai
3. Сообщение: короткое, с хуком (см. шаблон в interview-stories / outreach-файле)

### Фокус на русскоязычных рекрутеров
- В крипто-компаниях Дубая их много — имя/фамилия выдадут
- Сообщение можно писать на русском → конверсия выше
