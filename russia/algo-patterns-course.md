# 🎓 Курс паттернов алгоритмов — лестница от простого к сложному

> Цель: чтобы на секции фраза из условия мгновенно вызывала паттерн.
> Формат: в каждом паттерне 3 уровня — L1 (механика) → L2 (шаблон) → L3 (подвох/сборка).
> Решаем интерактивно: задача → твоё решение → ревью → эталон.
> Обновлено: 2026-09-17

---

## 📇 Шпаргалка-навигатор (выучить!)

| Читаю в условии | Паттерн |
|-----------------|---------|
| минимальное **количество шагов/прыжков** (шаги равной цены) | **1. BFS** |
| **острова/компоненты/закрасить связные** клетки | **2. DFS/компоненты** |
| максимум/минимум **суммы по пути**, движение R/D | **3. DP по сетке** |
| **количество способов**, «сколько путей» | **4. DP одномерное** (+ сетка со сложением) |
| **отсортировано** + пара/тройка с условием | **5. Два указателя** |
| частоты, «встречается/первый уникальный» | **6. HashMap/Set** |
| интервалы, «максимум мероприятий», расписания | **7. Сортировка + жадность** |
| «первое слово с префиксом», «граница» в монотонном | **8. Бинарный поиск** |

## Паттерн 1 · BFS (поиск в ширину)

**Идея:** очередь; клетки/состояния обрабатываются **слоями по расстоянию**; первый приход = кратчайший путь.
**Сигнал в условии:** «минимальное число ходов», шаги равной стоимости, движение в любую сторону.

- [ ] **L1. Лабиринт**: сетка `.`/`#`, из `S` в `E`, ходы вверх/вниз/влево/вправо. Найти длину кратчайшего пути.
- [ ] **L2. Конь**: доска 8×8, минимальное число ходов коня из клетки в клетку.
- [ ] **L3. Блохи** ✅ (разобрали): BFS от кормушки + сумма расстояний.

## Паттерн 2 · DFS / компоненты связности

**Идея:** рекурсивный/стековый обход «в глубину»; помечаем всю компоненту.
**Сигнал:** «острова», «области», «закрасить всё связное», количество компонент.

- [ ] **L1. Острова**: сетка 0/1 (1 — суша, связность по 4 сторонам). Сколько островов?
- [ ] **L2. Крупнейший остров**: размер максимальной компоненты.
- [ ] **L3. Пруды**: сколько компонент из нулей, полностью окружённых единицами?

## Паттерн 3 · DP по сетке

**Идея:** таблица dp, клетка зависит от «выше» и «левее»; движение только вперёд.
**Сигнал:** путь по сетке R/D + максимум/минимум суммы.

- [ ] **L1. Черепашка-максимум** ✅ (решил): max сумма + маршрут.
- [ ] **L2. Черепашка-пути с лужами** ✅ (разобрали): количество путей.
- [ ] **L3. Минимальная сумма пути**: то же, но min (ловушка: границы не копия, а накопление — сравни с L1!).

## Паттерн 4 · DP одномерное

**Идея:** dp[i] зависит от нескольких предыдущих; база + переход + ответ.
**Сигнал:** «количество способов», лестницы, размен, рюкзак.

- [ ] **L1. Лестница**: сколькими способами подняться на n-ю ступень шагами 1 или 2?
- [ ] **L2. Лестница с ценой**: cost[i] за ступень; старт с 0 или 1; минимум затрат до вершины.
- [ ] **L3. Размен**: монеты достоинений [1,5,10]; минимальное число монет на сумму S (или −1).

## Паттерн 5 · Два указателя

**Идея:** два индекса сходятся/расходятся на отсортированном/линейном данных.
**Сигнал:** отсортированный массив + пара с суммой/разностью; палиндром; «встреча с концов».

- [ ] **L1. Палиндром** ✅ (решил на CodeRun).
- [ ] **L2. Пара с суммой**: отсортированный массив, найти пару с суммой K за O(n).
- [ ] **L3. Тройка с суммой 0**: классика — фиксируем элемент + два указателя.

## Паттерн 6 · HashMap / Set (частоты)

**Идея:** один проход + память; O(n) вместо O(n²).
**Сигнал:** «встречается», «первый уникальный», «дубликат», «анаграмма».

- [ ] **L1. Сумма различных** ✅ / **Первые буквы** ✅ (решил на CodeRun).
- [ ] **L2. Первый неповторяющийся символ** строки.
- [ ] **L3. Группировка анаграмм**: сгруппировать слова по «одинаковым буквам».

## Паттерн 7 · Сортировка + жадность

**Идея:** отсортировать по правильному ключу → жадный выбор очевиден.
**Сигнал:** интервалы, расписания, «максимальное число мероприятий», дедлайны.

- [ ] **L1. Медиана трёх** ✅ (sort/sorted — выучил ловушку).
- [ ] **L2. Афиша**: n мероприятий с началом/концом; посетить максимум (сортировка по концу!).
- [ ] **L3. Переговорки**: минимальное число комнат для всех встреч (событийный поток / два указателя).

## Паттерн 8 · Бинарный поиск

**Идея:** монотонность → режем пополам за O(log n).
**Сигнал:** отсортировано; «первый, кто ≥ X»; префикс-подсказки.

- [ ] **L1. Поиск числа** в отсортированном массиве.
- [ ] **L2. «Простая подсказка» Яндекса**: словарь + префикс → первое подходящее слово (бинарный поиск по отсортированному словарю!).
- [ ] **L3. Поиск по ответу**: «минимальная скорость, чтобы успеть за час» — бинарный поиск по ответу.
