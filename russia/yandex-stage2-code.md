## ⚠️ КРИТИЧНО: ввод-вывод на CodeRun (не как в LeetCode!)

Там ввод через stdin, вывод через stdout. На Kotlin:

```kotlin
import java.io.BufferedReader
import java.io.InputStreamReader

fun main() {
    val br = BufferedReader(InputStreamReader(System.`in`))
    val n = br.readLine()!!.trim().toInt()              // одно число
    val list = br.readLine()!!.trim().split(" ").map { it.toInt() }  // массив в строке
    // ... решение ...
    println(listOf(1, 2, 3).joinToString(" "))          // вывод
}
```
- **Быстрый ввод для больших данных:** BufferedReader (readLine — может быть медленным на огромных входах)
- Вывод большого объёма: собрать в StringBuilder → один println (много println = TLE риск)
- `readLine()!!` может вернуть null в конце — циклы чтения до null: `while (true) { val line = br.readLine() ?: break }`
- Тренируй ИМЕННО этот шаблон — чтобы на секции не тратить 5 минут на «как читать ввод»

## 📚 Паттерны-шпаргалка (все 6 задач = эти 5 паттернов)

### 1. Частоты (HashMap/IntArray)
```kotlin
val freq = HashMap<Char, Int>()
for (c in s) freq[c] = (freq[c] ?: 0) + 1
// если только латиница — быстрее IntArray(26): freq[c - 'a']++
```

### 2. Two pointers (палиндром)
```kotlin
var i = 0; var j = s.length - 1
while (i < j) { if (s[i] != s[j]) return false; i++; j-- }
return true
```

### 3. RLE — серии
```kotlin
val sb = StringBuilder(); var i = 0
while (i < s.length) {
    var j = i
    while (j < s.length && s[j] == s[i]) j++
    sb.append(s[i]).append(j - i)   // буква + длина серии
    i = j
}
```

### 4. Уникальные / set
```kotlin
val sum = s.toSet().sum()               // сумма уникальных
val count = list.toHashSet().size       // количество различных
```

### 5. Время (flight) — модульная арифметика
```kotlin
// всё в минуты, полночь = переход через 0:
val total = ((arrive - depart) % (24 * 60) + 24 * 60) % (24 * 60)
// ((x % m) + m) % m — корректный положительный модуль!
```
